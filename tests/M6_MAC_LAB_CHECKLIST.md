# M6 managed-Mac lab checklist

Run manually; do not integrate into a production MJ tool.

```text
research/jxa/run_framework_probe.zsh
```

Record:

- macOS version/build
- Intel or Apple Silicon
- managed/unmanaged status if known
- Foundation import result
- AVFoundation import result
- Core Image import result
- any XProtect notification
- any Automation/TCC prompt
- whether invocation from After Effects behaves differently from Terminal

Do not test production media first. Start with disposable local fixtures, then a disposable SMB fixture.
